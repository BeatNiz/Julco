# Roadmap MVP

## Fase 1: Base

- Crear solución y proyectos. Estado: iniciado.
- Definir contratos principales. Estado: iniciado.
- Registrar decisiones técnicas. Estado: iniciado.
- Definir modelos de inspección. Estado: iniciado.
- Agregar configuración, historial y exportación base. Estado: iniciado.
- Validar compilación con .NET SDK. Estado: pendiente.

## Fase 2: CDP

- Detectar Chrome y Edge.
- Descubrir endpoints CDP.
- Conectar por WebSocket.
- Probar `DOM.getNodeForLocation`.
- Obtener `outerHTML` y `computedStyle`.
- Correlacionar target CDP con ventana bajo cursor.

## Fase 3: Captura

- Atajo global.
- Overlay de pantalla completa.
- Selección por clic.
- Selección por región.
- Lupa tecnica movible/redimensionable.
- Corrección por DPI y monitores.
- Pruebas de coordenadas con zoom y escala de Windows.

## Fase 4: Panel lateral

- Tema oscuro.
- Pestañas General, DOM, CSS y Computed.
- Botones para copiar HTML y CSS.
- Historial simple.
- Exportación JSON desde el resultado capturado.

## Fase 5: Capturas y exportación

- Captura del elemento.
- Captura de región.
- Exportación PNG.
- Exportación JSON mínima.

## Fuera del MVP

- Firefox.
- Sistema completo de plugins.
- Conversión a frameworks.
- IA o reconstrucción visual.
- Análisis avanzado de accesibilidad.
